## Current Modules

- [Access Control](./01-Access-Control/)

## Writing Principles

Each writeup should focus on:

- Vulnerability type
- Testing methodology
- Burp Suite usage
- Exploitation logic
- Root cause
- Remediation

Avoid writing only click-by-click solutions. A good writeup should show how the vulnerability was discovered, verified, and fixed.
